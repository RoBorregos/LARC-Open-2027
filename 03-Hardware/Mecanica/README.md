## 1. Descripción del área

El área de Mecánica es responsable del diseño, desarrollo, construcción y validación de los sistemas mecánicos del robot de LARC Open.

Su trabajo comprende el diseño CAD, la estructura del robot, los mecanismos, la integración física de componentes y la documentación técnica correspondiente.

El objetivo es desarrollar un sistema mecánico funcional, confiable y adaptable a las necesidades de la competencia, aprovechando los conocimientos y desarrollos de generaciones anteriores.

## 2. Responsabilidades generales

- Diseñar, revisar y actualizar los modelos CAD del robot.
- Desarrollar y documentar piezas, mecanismos y ensambles.
- Coordinar con Electrónica la integración física de los componentes.
- Evaluar posibles mejoras estructurales, funcionales y estéticas.
- Realizar pruebas y simulaciones mecánicas cuando corresponda.
- Mantener organizadas las versiones y la documentación del diseño.
- Colaborar con Programación y Electrónica para asegurar la compatibilidad de los sistemas.

Las metas específicas, los entregables y las fechas de cumplimiento se encuentran establecidos en la carta de compromiso del área.

## 4. Documentación y control de versiones

Los archivos editables de SolidWorks se almacenarán en OneDrive, procurando mantener una estructura organizada y un historial claro de versiones.

### Consideraciones generales

- Conservar identificables las versiones anteriores del diseño.
- Utilizar nombres claros para piezas y ensambles.
- Documentar las modificaciones importantes.
- Evitar duplicar archivos innecesariamente.
- Mantener actualizado el ensamble principal.
- Registrar las decisiones de diseño que afecten a otras áreas.

Las modificaciones relevantes deberán acompañarse de evidencias y registrarse en los Issues correspondientes.

## 5. Colaboración entre áreas

El desarrollo mecánico deberá mantenerse en coordinación con Electrónica y Programación.

### Electrónica

La colaboración con Electrónica permitirá considerar las dimensiones, distribución, conexiones y necesidades de montaje de los componentes electrónicos.

### Programación

La colaboración con Programación permitirá considerar el funcionamiento de los mecanismos, motores y sistemas de control.

Las decisiones que afecten a varias áreas deberán discutirse en conjunto para evitar incompatibilidades durante la integración.

## 6. Seguimiento del área

Las actividades y entregables se administrarán mediante GitHub Issues y GitHub Projects.

Cada actividad contará con un responsable, fecha compromiso y evidencias correspondientes.

Los avances se revisarán durante las juntas generales de los miércoles a las 5:00 p. m.

No será necesario modificar este README después de cada junta, ya que su propósito es describir el funcionamiento general del área.
